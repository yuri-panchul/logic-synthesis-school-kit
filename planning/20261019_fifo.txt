From the main plan (2026.10.19):

3. Review of AI-generated (Claude Code and GPT-6-Astra Codex) solutions to a question "how to create a FIFO design using CMOS 40105 MSI chip that must be functionally equivalent to the SystemVerilog FIFO in BGM repository". The task is not trivial since 40105 FIFO is controlled by pulses while FIFO in BGM repo samples Push and Pop on posedge clock. In addition, in 40105 does not allow to combinationally derive Pop from ~Empty signal - something wrong was going on there when Maya tried to do this. AI created several solutions, some of them are kind of stupid (like using 4017 to do a single FIFO push in 6 clock cycles), but I want Maya investigate all variants of AI-generated solutions and come up (with my help) with a good solution (it might be tricky, for example it may involve negedge D-flip-flops). This is a task for Maya.
