Custom FSM task cards

Every student gets a different sequence. The generator below picks distinct sequences and prints a task card for the student and an answer key for the teacher: the state table (state k = "the last k inputs match the first k bits of the sequence"), binary state encoding, minimized next-state equations (unused state codes are don't-cares), the gate chips and an estimate of the wires. All 120 tasks with 2-5-bit sequences were solved ahead of time to size this kit.

Design assumptions: Moore machine; the button is sampled by one spare 40174 flip-flop (synchronized input A); state bits S2..S0 in a 40174 without inverted outputs, so complemented literals use the 4069; Reset drives the active-low CLEAR of the 40174 through an inverter; when a gate type runs out, a wider gate with tied inputs or a NAND/NOR inverter is used.
