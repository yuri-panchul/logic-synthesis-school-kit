FIFO на 40105: одна операция за такт

Используйте внешний такт напрямую. Запросы и данные фиксируются по каждому положительному фронту; следующий спад запускает импульсы 40105. Последовательные записи выполняются в последовательных периодах, а push и pop могут быть активны одновременно.

Без делителя такта, счётчика фаз и счётчика заполнения. Прежняя схема с CD4017/CD4029 заменена. Сигналы для empty и full формирует сама 40105.

Ёмкость: собственная глубина микросхемы — 16 слов. Две параллельные FIFO дают width=8, depth=16, одна — width=4, depth=16. В исходном RTL по умолчанию глубина 10. Для сравнения используется тот же исходник с параметром depth=16; ограничение десять слов удалено вместе со счётчиком.

Временные условия: схема воспроизводит операции FIFO, наблюдаемые синхронной логикой по положительным фронтам. Внутренняя операция выполняется по спаду, поэтому данные и флаги устанавливаются в низкой половине того же периода. Их непрерывные диаграммы не совпадают с RTL сразу после положительного фронта. Используйте empty, full и read_data по положительным фронтам после установления; на исходных выходах готовности возможны короткие переходные импульсы.

Интерфейс и допустимые запросы

inputs:  clk, rst, push, pop, write_data[width-1:0]
outputs: empty, full, read_data[width-1:0]

Отладочного интерфейса и дополнительных внешних сигналов обмена нет. Сброс асинхронный, активен высоким уровнем. При непустой очереди read_data показывает старейшее слово. Потребитель считывает это прежнее слово по положительному фронту, на котором запрашивает pop.

pop  → !empty
push → (!full || pop)

Вызывающая схема должна соблюдать эти правила допустимой работы FIFO. Исходный RTL продвигает указатели даже при недопустимых запросах; 40105 не воспроизводит такое поведение. Чтение пустой очереди, включая push+pop при empty, не входит в условия эквивалентности. При empty значение read_data не определено. Одновременные push+pop при full поддерживаются.

Один внешний период на операцию

Событие тактаДействие
clk ↑Потребитель считывает прежнюю голову и флаги. Входные регистры фиксируют push, pop и write_data. SI возвращается в 0, SO — в 1, подготавливая входы FIFO.
clk = 1Захваченные запросы и данные устанавливаются; новая операция FIFO не запускается.
clk ↓SI повышается при захваченном push; SO понижается при захваченном pop. Обе операции могут выполняться в этом периоде.
clk = 0Внутренние переносы и флаги готовности завершают установление до следующего положительного фронта.
Следующий clk ↑Следующий запрос принимается сразу, в том числе очередной push. Пустой такт не вставляется.
on clk ↑: {D_hold, W, R} ← {write_data, push, pop}
rst = 1: {D_hold, W, R} ← 0

W_n = !W
R_n = !R
SI  = NOR(clk, W_n)       // LOW during clk HIGH
P   = NOR(clk, R_n)
SO  = !P                 // HIGH during clk HIGH

DIR_ALL = DIR_L & DIR_H   // one chip: DIR_ALL = DIR
DOR_ALL = DOR_L & DOR_H   // one chip: DOR_ALL = DOR
full  = !DIR_ALL
empty = !DOR_ALL

Сигнал clk подаётся непосредственно на входы ИЛИ-НЕ. По положительному фронту высокий clk блокирует импульсы до распространения новых W/R. К моменту спада W/R уже стабильны полпериода. Не заменяйте это отдельной задержанной инверсной ветвью такта и вентилями И без анализа её перекрытия с обновлением регистров.

Захваченные данные не меняются всю низкую половину периода. Изменение внешних запросов или данных после окна setup/hold положительного фронта не создаёт дополнительных операций. Если push остаётся высоким на нескольких положительных фронтах, в каждой следующей низкой половине периода происходит одна запись.

При full и push=pop=1: SI остаётся высоким в низкой половине периода. Если SI приходит раньше SO, FIFO ждёт свободного места; после его появления захваченная запись выполняется. Если SO приходит первым, последующий SI записывает в освободившееся место. Данные должны оставаться стабильными до завершения внутреннего переноса. Поэтому схема не предполагает узкого импульса на фронте.

DIR и DOR восстанавливаются после внутренних переносов даже при сохраняющемся высоком SI или низком SO. Они не являются простой инверсией этих импульсов. Такая работа и запись при удерживаемом SI после освобождения места описаны в документации TI, функциональное описание и рисунок 13.

Питание U5–U7: вывод 14 = +5 В, вывод 7 = GND. Входы 11 и 13 U6, а также 8, 9, 12 и 13 U7 соедините с GND; неиспользуемые выходы оставьте свободными.

Сброс очищает W/R и входные регистры данных и аннулирует содержимое FIFO. При W=R=0 получаются SI=0 и SO=1 при любом уровне такта. Удерживайте сброс до установления этих уровней, затем снимайте его с соблюдением времени восстановления регистров относительно clk. Кнопки ARM или отдельного переноса не нужны.

Временные ограничения однотактного интерфейса

T_HIGH > register clk→Q + request inversion + FIFO data setup
T_LOW  > strobe logic + FIFO settling + downstream logic + receiver setup

Также соблюдайте минимальные длительности высокого и низкого уровней SI/SO, удержание данных, перекос такта и параметры сброса. При одновременном чтении/записи полной FIFO низкой половины периода должно хватать на распространение свободного места ко входу и завершение записи до изменения D_hold по следующему положительному фронту. Это временной путь в половину такта, а не многотактная операция.

Для выбранной HC FIFO при 4,5 В TI указывает во всём температурном диапазоне минимальные высокий/низкий уровни SI по 24 нс, SO по 36 нс и удержание данных 38 нс; распространение SO→DIR может занимать 750 нс. Это параметры отдельной микросхемы, а не предельная частота всей макетной платы. Используйте медленную настройку готового тактового модуля, пока полные временные пути не проверены на реальном макете.

Неизменённый исходный RTL запускается с depth=16 и неподключёнными отладочными выходами. Каждый положительный фронт и установившийся результат после спада сравниваются с независимой очередью. Проверены последовательные операции без пустых тактов, заданные шесть циклов, заполнение/опустошение, одновременная операция при одном слове, замена при full, изменение входов после захвата, сброс во время работы и 2000 случайных допустимых циклов на конфигурацию. В трёх 8-битных запусках меняется порядок SI/SO.

Это поведенческая проверка, а не реальная сборка и не временная модель производителя. Новая модель учитывает восстановление готовности независимо от удерживаемого импульса и ожидающую запись при full. Прежняя модель связывала готовность со всей длительностью импульса; такая консервативная модель не подходила для проверки адаптера прямого такта и заменена. Электрический перекос, пути минимальной задержки и все временные запасы ещё нужно проверить на макете.
