A 40105 implementation of the RTL FIFO

Use two CD74HC40105E chips in parallel for the original 8-bit × 10-word configuration. Capture the inputs, perform a read before a write, and use an occupancy counter for the ten-word limit. The debug interface is omitted.

Scope of equivalence. This proposal matches FIFO transactions at shared sampling edges for valid requests. It uses a 10-phase clock derived from the assembled clock module; it is not a drop-in replacement driven by an arbitrary external clock. Data and flags settle during the cycle rather than immediately after its first edge. The circuit has been checked with a behavioral model, not built on a breadboard.

8 × 10

Original default parameters. Two FIFO chips; twelve IC packages total.

4 × 16

Compact alternative. One FIFO chip; six IC packages total. Requires changing the RTL parameters.

The RTL uses rising-edge push/pop, asynchronous active-high rst, and a combinational head word on read_data. Its default parameters are width=8, depth=10. The three debug_* ports are observations only; removing them does not change the queue.

Valid request contract:

pop  → !empty
push → (!full || pop)
read_data is meaningful only when !empty

The caller enforces these rules. The RTL itself does not mask requests with empty or full. Consequently, a 40105 cannot reproduce every possible raw RTL trace: an empty pop advances the RTL pointer but does not remove a word from an empty hardware FIFO. Simultaneous push/pop on an empty queue is excluded. Values of read_data while empty are not part of the contract.

A single 40105 stores sixteen 4-bit words. Two devices widen the word to eight bits; they still have sixteen physical word positions. The external count declares full at ten. Under the contract, at most ten positions are occupied; six remain unused. This is a logical capacity limit, not a reconfiguration of the chip.

2. Automatic timing

Connect the assembled 555 clock module to the CD4017 phase counter. Use its decoded output 0, PH0, as the shared FIFO clock for the input registers and surrounding synchronous logic. The CD4017 runs through all ten states without a shortened reset loop. One complete turn performs one FIFO transaction.

555 module, 10 Hz → CD4017 → PH0 = shared clk, 1 Hz
                         ├→ PH2 → read pulse (SO ↓)
                         ├→ PH5 → write pulse (SI ↑)
                         └→ PH8 → occupancy update

Sampling rule: surrounding registers use only the rising edge of PH0. After PH8 and propagation settling, the resulting flags and head word also agree with the RTL result. Between PH0 and PH8, read_data and the count flags may describe different intermediate states. Do not clock a consumer from PH2/PH5, or treat the public outputs as coherent throughout that interval. PH0 has a 10% duty cycle.

The 100 ms phase is a deliberately slow demonstration setting, not a maximum operating-frequency claim. For CD74HC40105 at 4.5 V, the datasheet specifies up to 750 ns for SO-to-DIR ripple and 600 ns for SI-to-DOR ripple over its full temperature range. The long phase gaps accommodate these transfers; the complete circuit still requires setup/hold, output-edge and loading checks on the actual board. Inputs must meet the CD40174 setup/hold requirements around PH0. TI timing tables.

3. Control equations

All signals below are active high except the read strobe SO and register clear CLR_n. W, R and D_hold are registers, not live button signals. Subscripts L/H identify the low/high nibble FIFO.

DIR_ALL = DIR_L & DIR_H
DOR_ALL = DOR_L & DOR_H
R_pre   = pop & DOR_ALL
W_pre   = push & (DIR_ALL | R_pre)

PH0 rising: {D_hold, W, R} ← {write_data, W_pre, R_pre}
rst = 1:    {D_hold, W, R} ← 0

SI       = PH5 & W
POP_PULSE= PH2 & R
SO       = !POP_PULSE
CLR_n    = !rst

COUNT_EN = W ^ R
CARRY_IN = !COUNT_EN
UP_DOWN  = W
PH8 rising: if COUNT_EN, N ← (W ? N+1 : N-1)
rst = 1: N ← 0

empty = !(N3 | N2 | N1 | N0)
full  = N3 & N1    // N is restricted to 0..10

At physical full (sixteen words in the compact variant), DIR_ALL=0. A valid simultaneous pop makes R_pre=1, so the OR term still permits a write. The read at PH2 creates space before SI rises at PH5. At logical full (ten words in the main design), the physical FIFO has spare space; the caller uses the separate full output to enforce the ten-word limit.

The abbreviated full decoder N3 & N1 equals N==10 for reachable states 0…10. It would also assert for some forbidden counts above ten. This design assumes the valid request contract; it does not add overflow protection to the source RTL. The counter uses binary mode, so it can represent ten; a decade counter would wrap from nine to zero.

Do not replace this with SI = clk & push and SO = !(clk & pop). A request changing during a high clock level can create another strobe. Data from a producer clocked at the same edge can also change before the gated write edge arrives. Capturing inputs and using later, separate phases removes those dependencies. Live DIR/DOR signals qualify captured requests, not the pulse duration.

Reset and starting a run

Connect rst to both FIFO MR inputs, CD4017 RESET, CD4029 PRESET ENABLE and the inverter producing CLR_n. Reset must remain asserted long enough for all devices to clear. It forces SI low and SO high, cancels captured commands and forces the phase counter to PH0. With no reset gating on SI, the cleared W register is what guarantees SI stays low during reset release. After reset release, the first useful capture occurs when the counter wraps back to PH0. Release reset away from a master-clock edge and allow its specified recovery time; do not interpret the reset-induced PH0 edge as a transaction.

6. One-chip FIFO variant

For the smaller teaching circuit, instantiate the reference RTL with width=4, depth=16. Keep one 40105, one 40174, the same 4017 phase generator, one 4081, one 4071 and one 4069. This alternative preserves word ordering and simultaneous read/write behavior, but has a different width and capacity from the original defaults.

DIR_ALL = DIR; DOR_ALL = DOR
R_pre = pop & DOR
W_pre = push & (DIR | R_pre)
SI = PH5 & W
SO = !(PH2 & R)
empty = !DOR
full = !DIR

Allocate the 40174 first four D/Q pairs to data[0…3], its fifth pair (13 → 12) to W, and sixth (14 → 15) to R. The four 4081 gates implement R_pre, W_pre, SI and POP_PULSE. One 4071 gate produces DIR | R_pre. Four 4069 inverters produce CLR_n, SO, empty and full. The 4029, 4070, 4002, second FIFO, second register package and second AND package are removed. PH8 is a settling milestone only; its 4017 output can be left open.

In this variant, !DIR and !DOR also reflect temporary internal activity. They are valid occupancy flags at the PH0 sampling edge after settling, not guaranteed continuous full/empty indications during a strobe. In particular, a transient !DIR does not prove sixteen stored words. The main 8 × 10 circuit avoids using those raw signals as its public count flags.

7. Verification and sources

The included regression compiles the actual reference file with its debug outputs unconnected. It compares both the proposal model and the original RTL with an independent queue, before the PH0 sampling update and after PH8 settling. The queue model for each 40105 uses its logical SI/SO behavior and deliberately different artificial settling delays for the two nibbles. It is not a manufacturer timing model.

PASS width=8 depth=10 cycles=2100 resets=10 full_pop_push=76 writes=1009 reads=1003
PASS width=4 depth=16 cycles=2134 resets=10 full_pop_push=76 writes=1053 reads=1047

Tests cover fill/drain, repeated wraparound, one-word simultaneous read/write, replacement at full, random legal traffic, raw inputs changing repeatedly after capture, exactly one strobe per accepted operation, and reset in each phase 1…9. Each configuration includes 2,000 random cycles. Read-data comparison is skipped when empty, as required by the contract.

What remains to check on a prototype

  1. At 10 Hz master clock, verify the 1 Hz PH0 output and one SO-low / SI-high phase per enabled request. Confirm both FIFO chips receive the same strobes.
  2. Check clock levels, edge slew, fan-out and setup/hold with the actual selected parts and wiring. A logical regression does not verify these electrical details.
  3. Write ten distinct bytes, including A5 and 3C; confirm full at ten, then pop them in order. At full, assert push and pop together and confirm that the old head is consumed and the new byte joins the tail.
  4. Assert reset during PH2 and PH5; verify empty after reset and no unintended write on release. Compare data and count flags only at the documented observation times.

This is a circuit proposal with reproducible logical validation. It does not claim transistor-level timing equivalence, continuous-waveform equivalence, or completed hardware qualification. Using an unrelated incoming clk while preserving the original port timing would require a different internally sequenced controller and a new timing analysis.
