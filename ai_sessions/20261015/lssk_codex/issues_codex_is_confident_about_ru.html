Вопросы, в которых Codex уверен

Я не установил сбоя первых демонстраций XOR или 4013, для устранения которого требовались бы добавленные буфер HCT, формирователь такта, внешние резисторы светодиодов или конденсаторы.

Эти дополнения удалены из обычных инструкций и перечней наборов. Здесь записаны конкретные подтверждённые функциональные ограничения; общие рекомендации по проектированию не выдаются за доказанные сбои ваших демонстраций. Непроверенные предположения находятся в отдельном файле неопределённостей.

Автоматический сумматор должен также проверять место в очереди результата

В вашем эталонном модулестроки 74–79 объединяют признаки достоверности обоих операндов с готовностью очереди результата. Оболочкав строках 28–34 превращает valid/ready в push/pop. Поэтому pop_A = pop_B = push_SUM = !empty_A & !empty_B & !full_SUM. Если извлекать A/B при полной SUM, операнды будут потеряны без сохранения результата. В такой реализации это определённая функциональная ошибка, а не свидетельство необходимости аналоговых вспомогательных компонентов.

Импульсный интерфейс 40105 отличается от тактового интерфейса RTL

В строке 36 LSSK выбран компонент CD74HC40105E. Его документация производителя, страница 2, задаёт положительный фронт SI для загрузки и отрицательный фронт SO для удаления. DIR означает готовность входа, DOR — достоверность выхода. Эталонная FIFO принимает push/pop на общем положительном фронте. Простое переименование CLK/PUSH/POP в SI/SO не даёт эквивалентного подключения.

Для ламп с обозначениями EMPTY и FULL: EMPTY = !DOR и FULL = !DIR после установления флагов. Если назвать DOR сигналом EMPTY или DIR сигналом FULL без инверсии, смысл меняется на противоположный. В перечнях учтены элементы И/НЕ из источника для нужных булевых функций и полярностей. Точная схема формирования импульсов остаётся отдельной непроверенной деталью реализации; необходимость конкретного дополнительного конденсатора, формирователя или регистра здесь не установлена.

Общий сброс инициализирует состояние достоверных слов FIFO. При DOR=0 выходные данные не представляют достоверное слово. Это свойства устройства, а не свидетельство измеренного сбоя.

Исключение для семисегментных индикаторов прямо указано в вашем курсе

Занятие 1.2 на Habr и строка 51 LSSK задают резисторы 560 Ом для обычного семисегментного индикатора с CD4511. Они оставлены только в соответствующих упражнениях, по одному на управляемый сегмент. Это отдельный случай от светодиодов и гребёнок с уже встроенным ограничением тока для первых занятий. Курс, занятие 1.2 · Документация CD4511.

Другие определённые исправления функций и количеств

  • Для полного проекта с тремя FIFO нужны три корпуса FIFO; одна штука из исходной таблицы его не покрывает.
  • Для июльской демонстрации с тремя индикаторами нужны три драйвера и три индикатора.
  • CD4077 содержит четыре двухвходовых элемента XNOR, а не трёхвходовые. Для исправления описания дополнительные компоненты не нужны.
  • У CD4019 общие управляющие входы Ka/Kb. Один корпус не даёт четырёх независимых управляющих битов маски. Каталог различает общий выбор вектора и вариант произвольной маски на базовых элементах.
  • Одна CD4086 даёт одну четырёхчленную функцию И-ИЛИ-НЕ. Для выбора по восьми членам нужно больше одной такой функции.
  • CD4511 — дешифратор BCD, а не шестнадцатеричного кода. У альтернативной DM9368 из источника другое подключение.

Ни один из этих фактов не устанавливает частоту отказов ваших демонстрационных схем и не обосновывает возврат удалённых вспомогательных деталей в первое занятие.
