Give each student a different sequence

Assign a binary pattern of length 2–4, for example 01, 001, 101 or 1011. Connect the already assembled 555 generator directly to the register clock inputs and set it to approximately 0.5–1 Hz. DATA is 1 while its button is held and 0 while released. RESET starts a fresh input stream.

Set DATA between clock edges. Each rising edge records one bit, so holding DATA for three rising edges enters the same bit three times. A pattern describes the button states at successive clock edges. MATCH indicates whether the most recent edge completed the pattern; it holds until the next edge. Overlaps count: 10101 contains two matches for 101.

Worked example: pattern 1011

States encode the length of the longest recognized prefix: S0=00 (none), S1=01 (1), S2=10 (10), S3=11 (101). RESET sets both state bits and MATCH to 0.

Define minterm index m = 4Q1 + 2Q0 + X. Then D1=m2∨m5∨m6, D0=m1∨m3∨m5∨m7, and Dmatch=m7. The eight minterms are the eight AND combinations of Q1/¬Q1, Q0/¬Q0 and X/¬X. Test 1011011: matches occur on samples 4 and 7.

Why this hardware covers every offered custom task

A Mealy recognizer for an L-bit pattern needs L prefix states here; for L≤4, two state bits are sufficient. Three inverted signals come from CD4069. Three CD4073 packages provide nine 3-input AND gates, enough to generate all eight minterms of (Q1,Q0,X). For each of D1, D0 and Dmatch, two 4-input OR gates feed one 2-input OR. Three CD4072 packages and one CD4071 therefore implement any three truth-table outputs over these inputs.

Use three CD40174 flip-flops to register Q1, Q0 and MATCH on the same rising edge of the assembled clock. Its reset is active low; invert the active-high RESET button with a spare CD4069 gate. A fourth inverter remains available to translate reset polarity for the alternative CD4076 if needed—follow that part’s own control truth table. Tie unused D inputs and all register control inputs to defined levels. CD4076 is supplied as the source’s alternative storage experiment; it does not add unlimited FSM capacity.

Unused state encodings for patterns shorter than four bits go to S0 with MATCH=0. Start from reset before each test stream. The minterm implementation has a guaranteed capacity for the stated 2–4 bit tasks. Longer patterns, independent event buttons, handshakes or arbitrary teacher-defined FSMs require a fresh state/gate/wire count and are outside this fixed kit.

Student hand-in

  1. A state diagram naming the recognized prefix at each state, including overlap transitions.
  2. A transition table, state encoding and three next-value equations.
  3. A pin-level wiring plan and gate allocation within the kit.
  4. Tests for a correct code, an almost-correct code, overlaps, reset midway through a code, and repeated bits when DATA is held across several clock cycles.
  5. A demonstration that state changes at clock edges and that DATA changes between edges do not immediately change the stored state.

Starter 01 uses both halves of a CD4013: seen_zero_next = NOT X, match_next = seen_zero AND X, with both flip-flops reset to 0. This correctly rejects an initial 1 and recognizes 01 without needing an implicit earlier zero.
