Задайте каждому ученику свою последовательность

Назначьте двоичную последовательность длиной 2–4, например 01, 001, 101 или 1011. Подключите готовый генератор 555 напрямую к тактовым входам регистров и установите около 0,5–1 Гц. DATA=1 при удержании кнопки и 0 при отпускании. RESET начинает новый поток входных данных.

Устанавливайте DATA между фронтами. Каждый положительный фронт записывает один бит, поэтому удержание DATA три фронта вводит один и тот же бит три раза. Последовательность описывает состояния кнопки на последовательных фронтах. MATCH показывает, завершилась ли последовательность на последнем фронте, и сохраняется до следующего. Перекрытия учитываются: в 10101 две последовательности 101.

Разобранный пример: последовательность 1011

Состояния кодируют длину самого длинного распознанного префикса: S0=00 (нет), S1=01 (1), S2=10 (10), S3=11 (101). RESET обнуляет оба бита состояния и MATCH.

Текущее состояниеВход 0: следующее / совпадениеВход 1: следующее / совпадение
S0 (00)S0 / 0S1 / 0
S1 (01)S2 / 0S1 / 0
S2 (10)S0 / 0S3 / 0
S3 (11)S2 / 0S1 / 1

Определим индекс минтерма m = 4Q1 + 2Q0 + X. Тогда D1=m2∨m5∨m6, D0=m1∨m3∨m5∨m7, а Dmatch=m7. Восемь минтермов — восемь комбинаций И из Q1/¬Q1, Q0/¬Q0 и X/¬X. Проверьте 1011011: совпадения приходятся на отсчёты 4 и 7.

Почему этих компонентов достаточно для всех предлагаемых индивидуальных заданий

Здесь распознаватель Мили для последовательности из L битов требует L префиксных состояний; при L≤4 достаточно двух битов состояния. CD4069 даёт три инвертированных сигнала. Три CD4073 дают девять трёхвходовых И — достаточно для всех восьми минтермов (Q1,Q0,X). Для каждого из D1, D0 и Dmatch два четырёхвходовых ИЛИ подаются на один двухвходовый ИЛИ. Поэтому три CD4072 и одна CD4071 реализуют любые три выходные функции таблицы истинности этих входов.

Используйте три триггера CD40174 для записи Q1, Q0 и MATCH по одному положительному фронту готового генератора. Сброс у этой микросхемы активен нулём; инвертируйте кнопку RESET с активной единицей свободным элементом CD4069. Ещё один инвертор остаётся для изменения полярности сброса альтернативной CD4076, если это понадобится; следуйте её таблице управления. Задайте постоянные уровни неиспользуемым D и всем управляющим входам регистров. CD4076 включена как альтернативный вариант хранения из источника и не даёт неограниченных возможностей конечному автомату.

Неиспользуемые коды состояний для последовательностей короче четырёх битов переводятся в S0 с MATCH=0. Перед каждым тестовым потоком начинайте со сброса. Минтермная реализация по числу элементов покрывает все указанные задания на 2–4 бита. Более длинные последовательности, независимые событийные кнопки, протоколы согласования или произвольные автоматы преподавателя требуют нового расчёта состояний, элементов и проводов и выходят за пределы фиксированного набора.

Что сдаёт ученик

  1. Диаграмму состояний с распознанным префиксом в каждом состоянии и переходами при перекрытиях.
  2. Таблицу переходов, кодировку состояний и три уравнения следующих значений.
  3. План соединений на уровне выводов и распределение элементов набора.
  4. Тесты правильного кода, почти правильного кода, перекрытий, сброса в середине кода и повторяющихся битов при удержании DATA несколько тактов.
  5. Демонстрацию изменения состояния по фронтам и того, что изменения DATA между фронтами не меняют сохранённое состояние немедленно.

Начальный вариант 01 использует обе половины CD4013: seen_zero_next = NOT X, match_next = seen_zero AND X, оба триггера сбрасываются в 0. Это корректно отвергает начальную 1 и распознаёт 01 без предположения о несуществующем предыдущем нуле.
